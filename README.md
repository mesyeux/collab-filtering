# Movie Recommendation System (Collaborative Filtering)

## Project Overview

This project implements a **movie recommendation system** using **collaborative filtering** methods.  
The program predicts movie ratings for users and recommends movies based on the highest predicted ratings.

---

## Features

- Item-item collaborative filtering
- Computes similarity between items with Pearson
- Predicts missing ratings for unrated movies
- Outputs recommended movies per user via command-line interface
